# Publication licensing and attribution review

Review date: 2026-11-02 (Asia/Kolkata). This records evidence and release choices;
it does not assert legal clearance for unverified assets.

The authoritative [IBM repository](https://github.com/IBM/telco-customer-churn-on-icp4d)
labels its code pattern Apache 2.0 and distinguishes third-party components.
The [upstream license](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/LICENSE)
was reviewed; an unmodified attribution copy is retained at
`third_party/IBM_TELCO_APACHE_LICENSE.txt`. The dataset originates from the
[IBM CSV source](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv).
The review did not establish a separate dataset-specific grant covering every
proposed derivative. No broad legal conclusion is inferred from GitHub accessibility.

Raw/cleaned data, SQLite DB, trained models and original provenance are withheld.
Public aggregate summaries contain no individual rows and describe recorded evidence;
approval of the source candidate does not approve a future binary/data release.
The proposed release bundles no dependency implementation code or third-party images.
Charts/screenshots are not assumed covered by a blanket license.

No root LICENSE has been added. Original-source ownership and the desired license
remain owner decisions. Code inspection found no embedded third-party copyright/copy
notices beyond project attribution, but cannot prove authorship or remove obligations.
If the owner confirms the original code is theirs to license, MIT is a reasonable
simple portfolio option; Apache 2.0 is another option if its patent provisions are
desired. Neither can relicense third-party material or grant unverified data rights.
Adding a root license requires separate explicit approval. Until then, describe
this as a source-visible portfolio candidate, not an openly licensed reusable package.

Public GitHub visibility and copying/forking permissions are governed by GitHub's
terms; public visibility alone does not grant a general open-source license. See
[GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
